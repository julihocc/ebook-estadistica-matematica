\begin{frame}{Principios de conteo}
  \small
  \begin{itemize}
    \item Regla de la suma para alternativas mutuamente excluyentes.
    \item Regla del producto para etapas sucesivas.
    \item El complemento permite contar resultados que no satisfacen una condición.
  \end{itemize}
  \begin{block}{Idea operativa}
    Describir primero el experimento y después identificar si el orden y la repetición importan.
  \end{block}
\end{frame}

\begin{frame}{Permutaciones y combinaciones}
  \small
  \begin{align*}
    P(n,r)&=\frac{n!}{(n-r)!}, & {n\choose r}&=\frac{n!}{r!(n-r)!}.
  \end{align*}
  Las permutaciones cuentan arreglos ordenados; las combinaciones cuentan selecciones sin orden.
  \begin{alertblock}{Criterio de selección}
    Si cambiar el orden produce un resultado distinto, se usan permutaciones; si no, combinaciones.
  \end{alertblock}
\end{frame}

\begin{frame}{Síntesis}
  \small
  Las técnicas de conteo proporcionan el puente entre espacios muestrales finitos y probabilidades clásicas:
  \begin{itemize}
    \item definen el denominador de un modelo equiprobable;
    \item permiten contar casos favorables sin enumerarlos;
    \item preparan el análisis de probabilidad condicional y muestreo.
  \end{itemize}
\end{frame}
